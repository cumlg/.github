# cumlg/.github

GitHub's special org repo. Nothing here is a workstream.

- [`profile/README.md`](profile/README.md) — the public landing page shown at
  [github.com/cumlg](https://github.com/cumlg).
- [`scripts/`](scripts/) + [`.github/workflows/`](.github/workflows/) — org-wide
  automation (e.g. the scheduled board sync).

**How we work lives in the [group handbook](https://cumlg.github.io/handbook/)**
(source: [`cumlg/handbook`](https://github.com/cumlg/handbook)) — that site is the
single source of truth for conventions; don't document them here.
